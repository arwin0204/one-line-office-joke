Entry for the make.fun bounty **One-Line Office Joke: 24-Hour Sprint** — a single-line joke about office life (at most 200 characters), written to `/output/entry.txt` for the judge to compare against other entries.

## The joke

> The office printer only works when IT is watching, so I booked a meeting with IT just to print one page.

## How to run

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when `OUTPUT_DIR` is set). The program checks the text is a single line of 1–200 characters before writing it.
